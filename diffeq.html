        Using the board

        • clickstart a solution from that point (the white curve)
        • drag / scrollmove around and zoom
        • double-tapreset the view

        Slope fields

        • type an equationor pick a chip. it is saved to History
        • Historyhover to compare, click to go back

        About

        Locus is an interactive math playground made by Nakita Ray. nakitaray.com

        Built with

        HTML, CSS and vanilla JavaScript on the Canvas 2D API. No frameworks or build step: the 3D renderer, plotting and expression parser are written from scratch. Equations are typeset with KaTeX.

        Credits

        Loader lettering: Chaos by Sigrid Liira (SUVA Type Foundry). Type: Dosis, Syne and Space Mono.
